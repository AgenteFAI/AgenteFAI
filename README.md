# AgenteFAI - Introducción a la Programación

Bienvenido. Este proyecto es una guía básica para aprender programación desde cero,
sin necesidad de experiencia previa.

## ¿Qué es programar?

Programar es darle instrucciones a una computadora para que haga algo.
Es como escribir una receta de cocina: una lista de pasos que se siguen en orden.

## ¿Qué lenguaje vamos a usar?

**Python** — es el lenguaje más fácil para empezar. Se lee casi como inglés
y no requiere configuraciones complicadas.

## Estructura del proyecto

```
AgenteFAI/
├── README.md              ← Estás aquí
├── 01_hola_mundo.py       ← Tu primer programa
├── 02_variables.py        ← Guardar información
├── 03_decisiones.py       ← Hacer que el programa decida
└── 04_repeticiones.py     ← Repetir acciones
```

## ¿Cómo ejecutar los ejemplos?

1. Asegúrate de tener Python instalado (versión 3)
2. Abre una terminal
3. Escribe: `python3 01_hola_mundo.py`

## Conceptos clave

| Concepto    | ¿Qué es?                                      | Ejemplo en la vida real          |
|-------------|------------------------------------------------|----------------------------------|
| Variable    | Un nombre para guardar un dato                 | Una caja con etiqueta            |
| Condición   | Una pregunta que se responde sí o no           | "¿Está lloviendo?"              |
| Bucle       | Repetir algo varias veces                      | Lavar cada plato de una pila    |
| Función     | Un grupo de instrucciones con nombre           | Una receta que puedes reutilizar |
